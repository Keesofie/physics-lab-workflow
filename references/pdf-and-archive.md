# PDF 输出

## 唯一交付文件

只输出一份实验报告 PDF。沿用用户指定的目录；没有指定时用当前项目的 `实验报告/`。已知实验日期可用于文件名，日期未知时省略日期，不用生成当天日期冒充实验日期。PDF 已存在时选择新的版本文件名，例如 `实验报告_v02.pdf`，不覆盖旧稿。

输出目录只新增这一个 PDF。正文源稿、计算脚本、图表和页面预览放内存或系统临时目录，不建立持久化 Markdown、Word、过程记录目录、图片附件或输入备份，不移动或删除用户原文件。工具自身依赖缓存不属于报告附件，但不得把过程材料以缓存为名另行归档。

留空项保留字段、表头和必要空白。示例 `同组者：________`；现象或讨论缺失时在对应小节用 `________` 和适量空白行保留填写位置。不能把未知写成“无”“未发现异常”或数字零。含空缺时标题后写一句“未提供的信息已留空，需本人补全。”，不输出缺项问卷。

## 渲染接口

本包不依赖某个 agent 的专属 API。推荐通过 Python 接口从内存生成 PDF，不保存正文源稿：

```python
from pathlib import Path
from render_report import render_text

render_text(report_text, Path("实验报告/实验报告.pdf"), base_dir=temporary_asset_dir)
```

也可通过标准输入传入 UTF-8 正文，`--base-dir` 指定临时图表所在目录：

```text
python <skill目录>/scripts/render_report.py - --base-dir <临时图表目录> --output <报告.pdf>
```

脚本仍可读取用户已有的 Markdown 输入文件，但不输出 Markdown。不要为调用它在报告目录新建源稿。跨平台需要正确设置标准输入 UTF-8 编码。

优先复用现有环境。缺依赖时在项目隔离环境安装 `scripts/requirements.txt`，不修改系统 Python；遇到权限或网络限制如实说明。PDF 为 A4，22 mm 页边距、11 pt 中文正文、17 pt 行距，带页码。输出已存在时拒绝覆盖。

中文字体按可用字体探测，也支持 `--font <TTF/TTC字体文件>` 和 `--font-index <TTC子字体序号>`；不随包复制本机字体。数学采用 Matplotlib MathText 子集，不依赖系统 TeX。

## 内部正文格式

- 一级标题为实验报告名称，后面是七部分标题。只有学案时也保留七部分；缺实际记录或计算所需数据的部分留空。
- 独立公式以单独一行的 `$$` 开始和结束，内联公式用 `$...$`。复杂公式拆成 MathText 支持的等价短式；不支持的公式需报错，不能静默删除。
- 原理图与曲线放临时目录，`![图题](相对路径)` 独立成段。图注明单位、图例和必要来源；不自动下载外部图片。缺原始数据时不生成模拟实验曲线。
- 表格各行列数一致，过宽时拆表，跨页重复表头。空读数用空单元格，列名和单位已知时保留；单位未知也留空。
- 只使用脚本支持的标题、段落、平铺列表、表格、局部图片和公式。它拒绝 HTML、嵌套列表和不支持的格式，避免漏掉内容。

## 检查与返回

按当前环境要求执行 artifact 操作标记（如有），该适配不改变只交付 PDF 的约定。

把 PDF 每页渲染到临时目录并逐页检查，核对中文、公式、上下标、表头、数值、分页和空白。可以用 `pdftoppm -r 120 -png <报告.pdf> <临时预览前缀>` 或已有等价渲染器；文本提取不能代替视觉检查。

需要 AI 使用说明或核算依据时，用同一 PDF 内的短注记及已有可见对话承载，不创建附件。没有可用渲染能力时说明未完成验收，不能宣称交付完成。问题修复后检查最新 PDF，再清理本次临时材料。最终仅返回 PDF 链接或 PDF 输出引用，不附源稿、预览图、代码或压缩包。
