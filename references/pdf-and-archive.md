# PDF 输出与归档

## 归档约定

优先沿用用户已有报告目录；没有时使用当前项目的 `实验报告/<日期_实验简称>/`。日期未知用 `日期待核对`，不以当前日期冒充实验日期。每次输出用新的 `v01/`、`v02/` 等子目录，保留原稿。

版本目录中：正文为 `预习报告.md/.pdf` 或 `实验报告.md/.pdf`；`过程记录/` 保存材料来源索引、原始记录转录、核算脚本/输入/输出、学生原话与判断依据、可见提示词和修改记录、AI 使用范围及未解决项。外部原始资料引用位置并保留备份，不能移动或覆盖原文件。AI 记录包含范围、模型/工具信息（已知时）、学生修改、验证方式，不虚构记录。

正文与过程记录分开。完整性状态由内容决定，不能由 PDF 命令成功决定。草稿的缺项必须在 PDF 开头清楚显示。需要填写的姓名等不能静默略去。

## 渲染脚本接口

本包核心不要求某个 agent 的 API；有 Python 环境时：

```text
python -m pip install -r <skill目录>/scripts/requirements.txt
python <skill目录>/scripts/render_report.py <源稿.md> --output <报告.pdf>
```

优先复用可用环境。缺依赖时在项目内建立 `.venv-physics-lab` 后安装，不修改系统 Python。依赖安装或文件访问被环境限制时如实报告，不反复重试未经授权的操作。迁移技能包不携带虚拟环境。

脚本接收 UTF-8 Markdown，输出 A4 PDF，默认 22 mm 页边距、11 pt 中文正文、17 pt 行距，带页码。支持标题、段落、列表、代码块、Markdown 表格、局部图片、内联和独立公式。输出已存在时拒绝覆盖；先创建新版本目录。

中文字体按可用字体探测，支持 `--font <中文字体文件>`、`--font-index <TTC子字体序号>`，不能因字体缺失输出黑方块；字体从目标机器获取，不随包复制版权字体。数学采用 Matplotlib MathText 的支持子集，不要求系统 TeX。

### 源稿约束

- 一级标题写报告名称，其后为七部分或五部分。缺项状态置于标题后第一段。
- 独立公式以单独一行的 `$$` 开始和结束。内联公式用 `$...$`。只使用 MathText 支持的符号；复杂分段/矩阵或多行环境拆成数条等价公式，不改变数学意义。不支持的公式必须报错，不能静默删除。
- 原理图、曲线等先保存本地图片，用 `![图题](相对路径)` 独立成段。外部图片链接不自动下载。图片要标单位、图例与必要来源；已生成的图题不要再在正文重复一遍。
- 表格控制列数与表头长度，过宽时拆表；脚本重复跨页表头并按实际宽度换行。它拒绝 HTML、嵌套列表和不支持的块格式，避免默默漏掉内容。
- 链接保留可读文字与目标；不支持的内容先改写成上述格式再导出。代码围栏只用于确需放正文的短内容，完整计算代码放过程记录。

## 检查与交付

创建 PDF 前按当前工具环境实际要求执行相应 artifact 操作标记（如果有）；这是工具适配要求，不是通用正文依赖。

用 `pdftoppm -r 120 -png <报告.pdf> <预览前缀>` 渲染每一页，逐页查看中文、公式、上下标、表头、曲线标签、分页、页码及空白，不能只做文本提取。若 Poppler 不可用可用现有等价渲染器；没有可用渲染能力时声明 PDF 未完成视觉验收。

核对 PDF 中的关键数值与源稿/核算输出，链接相应 PDF 和 Markdown。发现裁切或溢出，先修源稿或生成脚本，再重新导出到新的版本/验收临时文件；不得在没有检查新文件的情况下称问题已修复。
